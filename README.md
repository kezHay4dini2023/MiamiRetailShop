# MiamiRetailShop
This data analysis project investigates daily sales fluctuations for a [retail shop](https://github.com/Gaelim/youtube/blob/master/Miami%20Shops.zip) based in Miami. Currently, leadership lacks clear visibility into the primary drivers behind these sales variations.

By analyzing how weather patterns and customer demographics influence store performance, this project provides actionable insights to help leadership optimize inventory planning, staffing schedules, and promotional campaigns.
